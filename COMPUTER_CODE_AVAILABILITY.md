# Computer Code Availability

The complete code-cell extraction from the eight source notebooks is available in `extracted/`, with sanitized notebook copies in `notebooks/`. Reusable modules, command-line scripts, configurations, deterministic tests, and provenance records are included in this repository.

Large satellite imagery, generated NPZ patch archives, and trained model checkpoints are not redistributed. Full-scale execution requires the external inputs listed in `docs/DATASETS.md`. The repository does not claim data-free reproduction of GPU-scale experiments.
